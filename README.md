## Important

To open the app on Mac for the first time, make sure to allow it in Settings -> Privacy and Security -> Open Anyway

**The project is maintained by AI.**

- View and manage indices, documents, and mappings
- Monitoring of the cluster health and performance
- Execute complex search queries with filters and aggregations
- Explanation and Profiling of search queries
- API Playground
- Multi-window support
- Elasticsearch 8 and 9 support
- Dark mode support

### Install

```sh
yarn
```

```sh
yarn build
```

Development mode with hot-reload:

```sh
yarn dev
```

Development preview as an app:

```sh
yarn start
```

Test:

```sh
yarn test
```

Lint:

```sh
yarn lint
```

App build:

```sh
yarn dist-mac
yarn dist-win
yarn dist-linux
yarn dist #for all
```
